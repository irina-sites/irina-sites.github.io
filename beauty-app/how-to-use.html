Сияние 40+ 🌷

Приложение для ухода за кожей и гимнастики лица. Как всем этим пользоваться.

▶️ Как запустить на компьютере

  1. Дважды кликните по файлу «start-app.bat»
  2. Откроется чёрное окно — это сервер. Не закрывайте его, пока пользуетесь приложением
  3. Браузер откроется сам на странице приложения
  4. Чтобы остановить — просто закройте чёрное окно
Если браузер не открылся сам — откройте вручную адрес: http://localhost:8000/

🌍 Как опубликовать в интернете (бесплатно, за минуту)

Через Netlify Drop — без программиста и без аккаунта для старта:

  1. Откройте в браузере: app.netlify.com/drop
  2. Перетащите на страницу архив «Сияние40-сайт.zip» (лежит на рабочем столе)
  3. Подождите ~30 секунд — Netlify выдаст живую ссылку вида имя.netlify.app
  4. Готово! Ссылка работает на любом устройстве
Чтобы ссылка осталась навсегда — Netlify предложит создать бесплатный аккаунт (кнопка на той же странице). В настройках можно задать красивое имя: ваше-имя.netlify.app.

Чтобы обновить приложение после правок — попросите пересобрать архив и перетащите новый на вкладке «Deploys» вашего сайта.

📱 Как поставить на телефон

После публикации откройте ссылку на телефоне:

  • iPhone (Safari): «Поделиться» → «На экран Домой»
  • Android (Chrome): меню ⋮ → «Добавить на главный экран»

Появится иконка-цветок, приложение будет открываться на весь экран, работать без интернета и не отправлять данные никуда.

✏️ Как менять содержимое (без программиста)

Всё простыми текстовыми файлами в папке data:

  • data/articles.js — статьи в разделе «Знания»
  • data/routines.js — шаги ухода (утро / вечер)
  • data/exercises.js — упражнения гимнастики для лица
Проще всего — попросите меня внести правки. После изменений перезапустите .bat и обновите страницу.
