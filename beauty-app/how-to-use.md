# Сияние 40+ · Уход за кожей 🌷

Приложение для персонального ухода за кожей для женщин 40+.
Работает без интернета, без регистрации. Все данные хранятся только на устройстве пользователя.

---

## ▶️ Как запустить на компьютере

1. Дважды кликните по файлу **`start-app.bat`**
2. Откроется чёрное окно (это сервер — **не закрывайте его**, пока пользуетесь приложением)
3. Браузер откроется сам на странице приложения
4. Чтобы **остановить** — просто закройте чёрное окно

> Если браузер не открылся сам — откройте вручную адрес: `http://localhost:8000/`

---

## 🌍 Как опубликовать в интернете (бесплатно, за минуту)

Через **Netlify Drop** — без программиста и без аккаунта для старта:

1. Откройте в браузере: **https://app.netlify.com/drop**
2. Перетащите на страницу архив **`Сияние40-сайт.zip`** (лежит на рабочем столе)
3. Подождите ~30 секунд — Netlify выдаст живую ссылку вида `случайное-имя.netlify.app`
4. Готово! Ссылка работает на любом устройстве.

**Чтобы ссылка осталась навсегда** — Netlify предложит создать бесплатный аккаунт
(по кнопке на той же странице). В настройках сайта можно задать красивое имя:
`ваше-имя.netlify.app`.

**Чтобы обновить приложение** после правок — попросите пересобрать архив
и перетащите новый на вкладке «Deploys» вашего сайта на Netlify.

## 📱 Как поставить на телефон (как настоящее приложение)

После публикации откройте ссылку на телефоне:

- **iPhone (Safari):** «Поделиться» → «На экран Домой»
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран»

Появится иконка-цветок, и приложение будет открываться как обычное — на весь экран,
работать без интернета (офлайн) и не отправлять данные никуда.

---

## ✏️ Как менять содержимое (без программиста)

Всё простыми текстовыми файлами в папке **`data`**:

- **`data/articles.js`** — статьи в разделе «Знания».
  Скопируйте один блок статьи, поменяйте заголовок и текст.

- **`data/routines.js`** — шаги ухода (утро/вечер) под тип кожи и задачи.
  Каждый шаг — это строчка вида: заголовок + короткое описание.

После изменений просто перезапустите `.bat` и обновите страницу в браузере.

## 📂 Что где лежит

| Файл / папка | Что это |
|---|---|
| `index.html` | Главная страница приложения |
| `css/` | Внешний вид (цвета, шрифты) |
| `js/` | Логика работы экранов |
| `data/` | **Тексты**: статьи и шаги ухода — правьте здесь |
| `assets/icons/` | Иконка приложения |
| `start-app.bat` | Запуск на компьютере |

## 🔒 Приватность

Профиль, отметки ухода и фото «до/после» **никуда не отправляются** —
они хранятся только в браузере на устройстве пользователя.
