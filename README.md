# Портфолио — Ирина Мехоношина

Разработка сайтов: лендинги, многостраничные сайты, визитки, квизы для сбора заявок.

**Посмотреть локально:** двойной щелчок по «Открыть портфолио.bat» — откроется
в браузере на `http://localhost:8080/`. Чтобы остановить, закройте чёрное окно.

---

## Что в какой папке

Папки названы латиницей: из них складываются адреса страниц, а кириллица
в адресе превращается в нечитаемую мешанину вида `%D0%9F%D0%BE%D1%80...`.

| Папка | Что внутри | Адрес после публикации |
|---|---|---|
| — | Главная страница портфолио со всеми работами | `irina-sites.github.io/` |
| `irina/` | Сайт-визитка: услуги, цены, портфолио, форма | `/irina/` |
| `kedron/` | «КЕДРОН» — каркасные дома, 8 страниц, каталог и калькулятор | `/kedron/` |
| `shop/` | «ГЛИНА» — интернет-магазин керамики: каталог, корзина, заказ | `/shop/` |
| `audit/` | Аудит безопасности: страница услуги + обезличенный отчёт | `/audit/` |
| `deck/` | Презентация «КЕДРОН» — коммерческое предложение, 12 слайдов | `/deck/` |
| `infographic/` | Инфографика «Из чего складывается цена дома» | `/infographic/` |

## Что где поменять

**Контакты на визитке** — файл `irina/index.html`, в самом низу, блок `var CONTACTS`.
Там два поля: ник Telegram без символа @ и почта. Больше нигде их искать не нужно.

**Фотография на визитке** — файл `irina/foto.jpg`. Имя должно совпадать буква
в букву: блок «Кто будет делать» появляется, только если файл найден. Пока файла
нет, блок скрыт, и посетитель не видит ни пустого места, ни сломанной картинки.

**Фон первого экрана «Кедрона»** — `kedron/assets/hero.jpg`. Рядом лежит
`photo-license.txt`, где записано, откуда фото и на каких условиях используется.

**Цены и товары магазина** — `shop/js/data.js`, один список в начале файла.
Каталог, фильтры и корзина подхватят изменения сами.

**Расценки «Кедрона»** — `kedron/js/calc.js`, объект `PRICES` в начале файла.
Если поменяете их, не забудьте про инфографику: её цифры посчитаны из этих же
расценок вручную и автоматически не пересчитаются.

## Презентация и инфографика

`deck/` листается стрелками, пробелом, кликом и свайпом. Клавиша **F** —
во весь экран, **Ctrl+P** — сохранить в PDF: каждый слайд ляжет на свою страницу.

`infographic/` свёрстана как лист A4. **Ctrl+P** → «Сохранить как PDF» даёт готовый
файл для отправки заказчику.

---

## Служебные файлы

`Открыть портфолио.bat` и `start-server.ps1` нужны только для просмотра на вашем
компьютере. В интернет они не выкладываются.

---

Демо-проекты «КЕДРОН», «ГЛИНА» и «VIREO STUDIO» сделаны для портфолио: названия
компаний, телефоны и цены в них вымышленные. Вёрстка, фильтры каталога, корзина
и калькулятор — настоящие и работают.
